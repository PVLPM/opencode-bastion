# OpenCode Bastion 1.0 Implementation Plan

> **For agentic workers:** Execute task-by-task with TDD. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship the Agent Status pill and Agent Fleet panel described in the spec.

**Architecture:** Pure derivation in `src/model/` turns host SDK data into the view
models of `src/model/types.ts`. A thin Solid adapter in `src/data/` reads the host
store `ServerRef.data` and feeds the model. `src/ui/` renders view models only.

**Tech Stack:** TypeScript 7 strict, Solid 1.9 (host-provided), Vite 8 with
`@opencode/plugin/gui/vite`, Vitest 4 (+ happy-dom for `*.test.tsx`).

**Spec:** `docs/superpowers/specs/2026-11-24-bastion-v1-design.md`

## Global Constraints

- Host SDK: `@opencode/plugin@2.4.1`, `@opencode/client@2.4.1` (types + `@opencode/client/solid`).
- Only `solid-js`, `solid-js/web`, `solid-js/store`, `@opencode/plugin/gui`, `@opencode/client*` may be imported from packages in `src/`.
- Delegation tool name: `subagent`. Input: `agent`, `description`, `prompt`, optional `sessionID` (continuation). Child link: `state.metadata.sessionID`.
- `data.session.cost(root)` already includes all descendants; a child's `SessionInfo.cost` is its own.
- Context = `input + output + reasoning + cache.read + cache.write` of the latest assistant message, over `ModelInfo.limit.context`.
- Card title: `Agent Name • Session Name`.
- CSS classes prefixed `bn-`; colors only from native tokens with fallbacks.
- Respect `prefers-reduced-motion`: no ticker slide, no beams, no scanner.

## Review Focus

1. Child session with no messages loaded yet (just created) → status Running with activity "Starting…", no NaN durations.
2. Model missing from catalog / `limit.context` = 0 → context undefined, never 0% or Infinity.
3. Reported cost 0 with tokens > 0 and no models.dev match → cost undefined (not "$0.00").
4. Same child delegated twice (continuation) → one card; task text from the latest call; one "out" beam per new call.
5. Initial load of a finished family → no beams fire (beams only from live transitions).

### Task 1: Status, activity and usage derivation (`src/model/`)

**Files:** Create `src/model/status.ts`, `src/model/activity.ts`, `src/model/usage.ts`, `src/model/format.ts`; tests `test/model/*.test.ts`.

**Interfaces — Produces:**
- `deriveStatus(input: StatusInput): { status: AgentStatus; detail: string | undefined; error: string | undefined }` where
  `StatusInput = { running: boolean; permissions: number; forms: number; info: SessionInfo; messages: readonly SessionMessageInfo[] }`.
  Rules (spec table): forms>0 → waiting "Waiting for your answer"; permissions>0 → waiting "Waiting for permission"; running → running (detail "Retrying (attempt N)" when the latest assistant has `retry` and no `completed`); idle: `info.outcome` or latest `idle` message outcome: succeeded → done, failed → failed (error = that message's `error.message` or latest assistant `error.message`), interrupted → unknown "Interrupted"; no outcome → unknown.
- `deriveActivity(messages, status): string | undefined` — from the newest assistant message's last content part:
  tool running/streaming: `read`→`Reading {basename(filePath)}`, `edit|write|patch`→`Editing {basename(filePath)}` (patch without path: `Editing files`), `shell`→`Running {description}` else `Running command`, `grep|glob|list`→`Searching {pattern|path}` else `Searching repository`, `webfetch`→`Fetching {url host}`, `websearch`→`Searching the web`, `subagent`→`Delegating to {agent}`, `skill`→`Loading {name} skill`, `question`→`Asking a question`, other→`Using {name}`; reasoning without `time.completed` → `Thinking…`; text in an incomplete message → `Writing response…`; status running with no assistant yet → `Starting…`. Waiting → the status detail + `…`. Retrying → `Retrying request…`. Idle → undefined. Never include reasoning text, prompts, commands or file contents.
- `contextUsage(messages, limit: number | undefined): ContextUsage | undefined` — latest of {assistant with tokens, completed compaction}; compaction newest → undefined; limit falsy → undefined.
- `sessionInterval(info: SessionInfo, running: boolean): { startedAt: number; endedAt: number | undefined }` — start `time.created`; end `time.idle` when not running and `time.idle >= time.created`, else latest message time when idle, else undefined.
- `format.ts`: `formatDuration(ms)` (`12s`, `4m 05s`, `1h 02m`), `formatMoney(money)` (`$0.29`, `<$0.01`, `~$0.29` when estimated), `formatTokens(n)` (`12.4k`, `1.2M`).

- [ ] Table-driven failing tests per rule above (one row per rule, synthetic SDK objects in `test/fixtures.ts` builders), run `pnpm vitest run test/model` → FAIL.
- [ ] Implement; run → PASS. `pnpm lint && pnpm typecheck`.
- [ ] Commit `feat(model): derive agent status, activity and usage`.

### Task 2: Delegations, beams, cost and fleet composition (`src/model/`)

**Files:** Create `src/model/delegations.ts`, `src/model/pricing.ts`, `src/model/fleet.ts`; tests in `test/model/`.

**Interfaces — Produces:**
- `delegations(rootMessages): Map<childSessionID, { toolID: string; agent: string; description: string | undefined; prompt: string | undefined; done: boolean }>` — latest call wins per child.
- `detectBeams(prev: BeamSnapshot | undefined, next: BeamSnapshot): Beam[]` with `BeamSnapshot = { toolIDs: ReadonlySet<string>; running: ReadonlySet<string> /* child ids */; delegationTargets: ReadonlyMap<string /* toolID */, string /* child id */> }`. `prev` undefined → `[]`. New toolID → `out` beam to its child. Child in `prev.running` but not `next.running` → `in` beam. Beam `id` = `${direction}:${sessionID}:${toolID or idle-transition counter}` unique.
- `pricing.ts`: `type PriceTable` (parsed `https://models.dev/api.json`: `{[provider]: {models: {[model]: {cost?: {input, output, cache_read?, cache_write?}}}}}`), `estimateCost(tokens: TokenUsageInfo, model: {providerID, modelID}, table, canonical?: string): number | undefined` — per-million prices; lookup provider/model, then canonical provider, then the unique model id across providers; no match → undefined. `resolveCost(reported: number, tokens, model, table): Money | undefined` — reported > 0 → `{usd, estimated:false}`; tokens all zero → `{usd:0, estimated:false}`; else estimate or undefined.
- `buildFleet(input: FleetInput): FleetView` — composes Task 1 functions; `FleetInput` = `{ root: SessionSnapshot; children: SessionSnapshot[]; currentID: string; agentName(id: string): string; modelLabel(ref?: ModelRef): ModelLabel | undefined; contextLimit(ref?: ModelRef): number | undefined; price(tokens, ref?): Money | undefined /* bound resolveCost */; familyCost: number }` and `SessionSnapshot = { info: SessionInfo; running: boolean; messages: readonly SessionMessageInfo[]; permissions: number; forms: number; lines: LineStats | undefined }`. Sorting per `types.ts`. `totalCost` = `price` over the family when any member is estimated, else `familyCost` reported.

- [ ] Failing tests incl. Review Focus 3, 4, 5; implement; PASS; lint/typecheck.
- [ ] Commit `feat(model): compose fleet view, delegations, beams and cost`.

### Task 4: Host adapter and plugin wiring (`src/data/`, `src/gui.tsx`)

**Files:** Create `src/data/fleet-source.ts`, `src/data/lines.ts`, `src/data/models-dev.ts`; modify `src/gui.tsx`; tests `test/data/*.test.ts` with a fake `FleetData`.

**Interfaces — Consumes:** Tasks 1–3. **Produces:** `createFleetSource(host: FleetHost): { fleet: Accessor<FleetView | undefined>; beams: Accessor<readonly Beam[]> }` where `FleetHost` is the narrow pick of `ctx.sessions`, `ServerRef.data` and `ServerRef.client.session.diff` actually used.
Behavior: routed session → `data.session.root(id)`; `session.sync(root, {children:true})`, then `message.sync`, `permission.sync`, `form.sync` for root and direct children (re-run for new children and when `server.connected` turns true). Lines via `client.session.diff({sessionID})` keyed by the session's latest completed assistant message time (no timers). models.dev table fetched once lazily only when a cost needs estimating; failure → no estimate. A 1 s clock signal runs only while some agent is running. Beams expire after the animation (900 ms).
`gui.tsx`: `Style`, `ComposerPill` (`run` reveals the panel via `Layout.state/open` key `${ctx.id}:fleet`), `Panel` id `fleet` (side, title "Agent Fleet"), `Command` "Open Agent Fleet", `MenuItem` on `session.panel`. Card open → `ctx.tabs.open({server, id}, {focus:true})` when `!data.session.missing(id)`.

- [ ] Tests: session switch re-anchors; reconnect re-syncs; child discovered later gets synced; missing session not openable. PASS.
